# คู่มือการใช้งานและการต่อวงจร ESP8266 Wi-Fi Tool

เอกสารฉบับนี้รวบรวมข้อมูลเกี่ยวกับการต่อสายฮาร์ดแวร์ การตั้งค่าปุ่มกด รายละเอียดฟังก์ชันเมนู และขั้นตอนการใช้งานเครื่องมือทดสอบเครือข่าย Wi-Fi ด้วยบอร์ด ESP8266 และจอแสดงผล OLED SSD1306

---

## 1. การต่อวงจรฮาร์ดแวร์ (Wiring)

การต่อสายไฟที่ถูกต้องและแน่นหนาเป็นสิ่งสำคัญมาก เนื่องจากชิปวิทยุของ ESP8266 จะดึงกระแสสูงในช่วงที่ส่งแพ็กเกจข้อมูล

| ขาอุปกรณ์ (Component) | ขาบนบอร์ด ESP8266 (NodeMCU / Wemos D1) | หน้าที่ / คำอธิบาย |
| :--- | :--- | :--- |
| **OLED VCC** | $3.3\text{V}$ หรือ $5\text{V}$ | จ่ายไฟเลี้ยงให้หน้าจอ |
| **OLED GND** | GND | กราวด์ (Ground) |
| **OLED SDA** | GPIO 4 (D2) | รับ-ส่งข้อมูล I2C (Data) |
| **OLED SCL** | GPIO 5 (D1) | สัญญาณนาฬิกา I2C (Clock) |
| **Button UP** | GPIO 14 (D5) | ปุ่มเลื่อนขึ้น / เปลี่ยนช่อง / สลับค่า |
| **Button DOWN** | GPIO 12 (D6) | ปุ่มเลื่อนลง / เปลี่ยนช่อง / สลับค่า |
| **Button SELECT**| GPIO 13 (D7) | ปุ่มยืนยัน / เริ่มทำงาน / หยุดการทำงาน |

*หมายเหตุ: ปุ่มกดทั้งหมดใช้โหมด `INPUT_PULLUP` ขาอีกด้านของปุ่มกดแต่ละตัวจึงต้องต่อลง **GND***

---

## 2. โครงสร้างเมนูและการทำงาน

เครื่องมือนี้มีระบบเมนู 4 ฟังก์ชันหลักที่แสดงผลบนจอ OLED:

1. **`1. Scan Wi-Fi`**
   * ทำการสแกนหาเครือข่าย Wi-Fi รอบข้าง
   * แสดงจำนวนเครือข่ายที่พบทั้งหมด และแสดงชื่อ SSID พร้อมหมายเลขช่องสัญญาณ (Channel) สูงสุด 3 เครือข่ายแรก
   * กดปุ่ม **SELECT** เพื่อออกจากหน้าจอผลการสแกนกลับสู่เมนูหลัก

2. **`2. Dis Wi-Fi 1`**
   * เจาะจงเลือกช่องสัญญาณเดียวที่ต้องการ ($1$ ถึง $13$)
   * ทำการปล่อยแพ็กเกจ Hidden Beacon และ Deauth จำนวนหนาแน่นถึง **100 ตัวต่อรอบ** บนช่องสัญญาณนั้น

3. **`3. Dis Wi-Fi 1-14`**
   * ทำการสลับช่องสัญญาณวนลูปแบบต่อเนื่องตั้งแต่ช่อง $1$ ถึง $14$
   * กระจายส่งแพ็กเกจผสมจำนวน **100 ตัวต่อรอบ** ครอบคลุมทุกย่านความถี่

4. **`4. Custom Multi-Ch`**
   * อนุญาตให้คุณเลือกเปิด/ปิดช่องสัญญาณที่ต้องการใช้งานได้ด้วยตนเอง
   * **ค่าเริ่มต้น (Default):** ช่องที่ **$1$, $6$, และ $11$** จะถูกตั้งเป็นสถานะ **`[ON]`** ส่วนช่องอื่นๆ เป็น **`[OFF]`**
   * ใช้ปุ่ม **UP/DOWN** เลื่อนเลือกช่อง $1$ ถึง $14$ หรือเลื่อนลงไปที่ปุ่ม `[ START RUNNING ]` ด้านล่าง กด **SELECT** เพื่อสลับสถานะเปิด/ปิด (`ON`/`OFF`) ของแต่ละช่อง
   * เมื่อเลือกช่องเสร็จแล้ว ให้เลื่อนไปที่ `> [ START RUNNING ]` แล้วกด **SELECT** เพื่อเริ่มรันระบบ

---

## 3. ขั้นตอนการใช้งาน (Step-by-Step)

1. **เปิดเครื่อง:** เสียบบอร์ด ESP8266 เข้ากับแหล่งจ่ายไฟ USB หน้าจอ OLED จะบูตขึ้นมาพร้อมแสดงเมนูหลัก (`== ESP8266 TOOL ==`)
2. **การควบคุม:** 
   * กดปุ่ม **UP** หรือ **DOWN** เพื่อเลื่อนเคอร์เซอร์ (`>`) เลือกเมนูที่ต้องการ
   * กดปุ่ม **SELECT** เพื่อเข้าสู่ฟังก์ชันนั้นๆ
3. **การหยุดการทำงาน:**
   * ในขณะที่หน้าจอกำลังรันฟังก์ชันตัดสัญญาณหรือหน้าจอโหลด คุณสามารถกดปุ่ม **SELECT** หนึ่งครั้งเพื่อหยุดลูปการทำงานและกลับสู่เมนูหลักได้อย่างปลอดภัย

---

## 4. ข้อจำกัดและข้อมูลทางเทคนิค

* **ความหนาแน่นของแพ็กเกจ:** ถูกตั้งค่าให้ยิงสูงถึง **100 แพ็กเกจต่อรอบลูป** เพื่อสร้างความหนาแน่นสูงสุดในอากาศ
* **กำลังส่งวิทยุ:** บอร์ดถูกบังคับให้ใช้กำลังส่งสูงสุด (`WiFi.setOutputPower(20.5);`) เพื่อขยายรัศมีคลื่นให้กว้างขึ้น
* **ข้อจำกัดด้านความปลอดภัยยุคใหม่:** เร้าเตอร์และสมาร์ตโฟนรุ่นใหม่ที่ใช้งานระบบป้องกัน **PMF (Protected Management Frames / 802.11w)** หรือมาตรฐาน WPA3 จะมีการเข้ารหัสคำสั่งการจัดการ ทำให้แพ็กเกจคำสั่งตัดการเชื่อมต่อแบบทั่วไปถูกมองว่าเป็นของปลอมและถูกละเลยตามมาตรฐานความปลอดภัยสากล
